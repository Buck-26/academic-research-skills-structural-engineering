# Structural Engineering Glossary (English / Turkish)

Civil/structural fork addition. Used by every agent when writing or reviewing papers in structural, earthquake or structural-dynamics engineering. It keeps terms consistent within a manuscript and between its English and Turkish versions (abstract, *Öz*, theses). Where a Turkish code (TBDY 2018, TS 500, ÇYTHYE) defines a term, the Turkish column follows the code's wording. Check it against the code edition the manuscript cites.

**Rule:** pick one English term per concept and keep it. Don't alternate synonyms such as "lateral load", "horizontal load" and "seismic load" for the same quantity.
